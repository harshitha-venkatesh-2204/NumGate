Method notes
  • Rates pool numbers or claims over notes.
  • Intervals are 95% percentile bootstrap intervals over notes (1,000 resamples), computed in the browser, so they can differ slightly from results/summary.csv.
  • S2 notes whose facts script failed twice are excluded from rates.
  • Gate v1 flags come from re-scoring the same notes with the first version of the gate (paper/rescore_v1.py).
  • The hand check is the paper's adjudication of the pilot.
  • Rebuild this page with python src/analyze.py.
